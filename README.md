# Родословная: лендинг

Статичный сайт, публикуется на GitHub Pages через `.github/workflows/pages.yml` при пуше в `main`.

- `/` : версия 2 (сегменты «себе» и «подарок родителям», гипотезы H05–H08).
- `/v1/` : эталонная версия 1.
- Заявки уходят в Formspree. До запуска рекламы заменить на сервис с хранением в РФ.
- A/B заголовка: `?h=b` или `?h=c`.
- Свой домен: файл `CNAME` в корне и DNS (A-записи 185.199.108–111.153).

Исходники и история правок: репозиторий `side_hustler`, папка `projects/02-ai-genealogy/landing/`.
